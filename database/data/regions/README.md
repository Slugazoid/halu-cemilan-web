# Data referensi wilayah

CSV wilayah ini dibundel dari `@nusawilayah/data` versi `2025.2.5`:
https://github.com/cuikww/nusawilayah/tree/main/packages/data

Kode dan nama wilayah bersumber dari Kepmendagri No. 300.2.2-2430 Tahun 2025.
Data paket menyebut turunannya berasal dari
[`cahyadsn/wilayah`](https://github.com/cahyadsn/wilayah) dan
[`cahyadsn/wilayah_kodepos`](https://github.com/cahyadsn/wilayah_kodepos),
berlisensi MIT. Pertahankan atribusi ini saat mendistribusikan ulang data.
Kode pos merupakan data upaya terbaik (best-effort), bukan jaminan resmi; nilai
yang kosong didukung dan disimpan sebagai `NULL`. Paket pengemas memakai lisensi
MIT (lihat `NUSAWILAYAH-LICENSE`). Kode wilayah bertitik pada CSV dinormalisasi
oleh seeder menjadi kode digit sesuai panjang kolom pada skema PRD.
